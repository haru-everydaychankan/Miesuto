# mikke｜お店の在庫チェック（デモ版）

スマートフォンを想定した、店舗の商品在庫を確認するためのデモアプリです。HTML・CSS・JavaScriptを `index.html` 1ファイルにまとめています。

## デモでできること

- **ホーム**：お気に入り店舗／全店舗の商品在庫を表示
- **店舗**：店舗を検索・選択し、カテゴリー別に在庫を確認
- **マイページ**：お気に入り店舗の登録・解除、所持ポイントの表示
- 商品をタップ：店舗ごとの在庫詳細を表示
- カテゴリー切り替え：食品・飲料・日用品・文房具で絞り込み
- お気に入り店舗の登録状態は、同じブラウザー内に保存

## GitHubにアップロードする方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダーの `index.html` と `README.md` をリポジトリの直下にアップロードします。
3. 公開デモにする場合は、リポジトリの **Settings → Pages** を開き、公開元を `Deploy from a branch`、ブランチを `main`、フォルダーを `/(root)` に設定して保存します。
4. 少し待つと、GitHub Pagesに表示されたURLからアプリを開けます。

## 注意

店舗名、距離、営業時間、商品、在庫数、会員情報、ポイントはすべて架空のデモデータです。実際の店舗や在庫、位置情報、通知サービスとは連動していません。外部ライブラリやAPIは使用していません。
